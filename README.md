BBC News — Advanced NLP: NER, Topic Modeling & Transfer Learning

Week 6 Internship Task — Advanced Natural Language Processing

This project applies three advanced NLP techniques to the BBC News dataset: Named Entity Recognition, Topic Modeling, and Text Classification using Transfer Learning. Together, these represent the kind of NLP pipeline used in media analytics, financial intelligence, and news aggregation platforms.

Objective

Go beyond basic sentiment analysis to explore:

Named Entity Recognition (NER) — extract people, organizations, locations, and other entities from news articles.
Topic Modeling — discover hidden themes across the corpus using unsupervised learning.
Transfer Learning — classify articles into categories using a pretrained language model, benchmarked against a traditional ML baseline.
Dataset
Name: BBC News Dataset
Source: Kaggle — gpreda/bbc-news
Description: 2,225 BBC news articles across five categories — business, entertainment, politics, sport, and technology.

Methodology
Part 1 — Named Entity Recognition

Entities (PERSON, ORG, GPE/LOC, DATE, MONEY, EVENT) are extracted from every article using spaCy's pretrained English model (en_core_web_sm). Entity frequencies are analyzed overall and broken down by news category, with visualizations and example articles.

Part 2 — Topic Modeling

Articles are vectorized with CountVectorizer and modeled using Latent Dirichlet Allocation (LDA) with 5 topics — chosen to align with the dataset's five known categories, enabling direct comparison via cross-tabulation. Topic quality is evaluated using a topic diversity score.

Part 3 — Transfer Learning vs. Traditional ML
Transfer Learning: A pretrained DistilBERT (distilbert-base-uncased) model is used as a frozen feature extractor; a Logistic Regression classifier is trained on the extracted embeddings.
Baseline: A traditional TF-IDF + Logistic Regression pipeline is trained on the same classification task for comparison.
Both approaches are evaluated using Accuracy, Precision, Recall, and weighted F1-score, and compared visually. The best-performing model is saved to models/ for future use.
Results Summary
Model	Accuracy	Precision	Recall	F1 Score
DistilBERT (Feature Extraction)	0.9865	0.9867	0.9865	0.9866
Traditional ML (TF-IDF + Logistic Regression)	0.9910	0.9911	0.9910	0.9910

The traditional TF-IDF + Logistic Regression baseline slightly outperformed the DistilBERT feature-extraction approach, likely because BBC News categories are already well-separated by vocabulary, which TF-IDF captures effectively.

How to Run
Clone this repository:
bash
   git clone https://github.com/<your-username>/bbc-news-advanced-nlp.git
   cd bbc-news-advanced-nlp
Install dependencies:
bash
   pip install -r requirements.txt
   python -m spacy download en_core_web_sm
Open and run the notebook:
bash
   jupyter notebook notebooks/week6_advanced_nlp.ipynb
